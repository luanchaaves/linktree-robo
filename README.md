## 🚀 Como Publicar no seu Domínio (`roboledpartner.com.br`):

### Opção A: Como Subpasta (`roboledpartner.com.br/links`)
1. No seu servidor de hospedagem (cPanel, FTP, Hostinger, KingHost, VPS, etc.):
2. Acesse a pasta `public_html` (ou raiz do site).
3. Crie uma pasta chamada `links`.
4. Envie todos os arquivos (`index.html`, `style.css`, `script.js` e a pasta `assets/`) para dentro de `/links/`.
5. Pronto! O link para colocar na bio do Instagram e TikTok será:
   `https://roboledpartner.com.br/links`

### Opção B: Como Subdomínio (`links.roboledpartner.com.br`)
1. No seu gerenciador de DNS / Hospedagem, crie o subdomínio `links.roboledpartner.com.br`.
2. Aponte a pasta raiz desse subdomínio para a pasta contendo estes arquivos.
3. Seu link na bio será:
   `https://links.roboledpartner.com.br`

### Opção C: Cloudflare Pages / Vercel / Netlify (Grátis com CDN Global)
1. Crie um repositório no GitHub ou faça o upload direto da pasta na [Vercel](https://vercel.com) ou [Cloudflare Pages](https://pages.cloudflare.com).
2. Conecte o domínio customizado (ex: `links.roboledpartner.com.br`).
3. O deploy é instantâneo com HTTPS automático e carregamento em milissegundos.
